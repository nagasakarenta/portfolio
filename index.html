課題

自分が 16 日で基本情報に合格するために作っていた実力テストと復習ノートを、誰でも使える形に設計し直す。

解決

分野別ドリル、SM-2 を単純化した間隔反復、本試験と同じ配分・制限時間の模試と合否判定、弱点分析。サーバ不要でデータはブラウザ内に。

技術

TypeScript。GitHub Actions で CI と GitHub Pages への自動デプロイ。自作した 434 問 ＋ 84 問のオリジナル問題をスクリプトで変換して収録。
